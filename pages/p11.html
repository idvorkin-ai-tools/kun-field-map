Repositories covered on this map

Grouped by the arc that covers them.

Interfaces for agents (p02, p03)

  • axi: the design principles and the benchmark harness behind them.
  • gh-axi: a GitHub CLI wrapper built to the AXI rules.
  • chrome-devtools-axi: browser automation for agents, built on Chrome DevTools.
  • quota-axi: lets an agent read your LLM subscription's quota windows.
  • tasks-axi: a task and backlog CLI with pluggable backends (markdown, SQLite, remote trackers).

The human in the loop (p04, p05)

  • lavish-axi: an editor for reviewing and annotating the HTML artifacts agents produce.
  • no-mistakes: a local git remote that runs an AI validation pipeline before anything reaches origin. Docs site: kunchenguid.github.io/no-mistakes.

Running many agents (p06, p07)

  • treehouse: a pool of reusable git worktrees, leased to one agent session at a time.
  • gnhf: "good night, have fun", a bounded overnight loop of small, committed agent changes.
  • firstmate: you talk to one agent, and it dispatches and supervises a crew of others.
  • compact-adviser: tells you when a session has reached a point where it is safe to compact.

Memory you train (p08)

  • backpass: reads past agent transcripts and proposes evidence-backed edits to AGENTS.md.
  • vision: an agent skill that drafts a VISION.md from a repo's history and stress-tests it with you.

Side builds (p09, p10)

  • autopreso: turns live speech into a whiteboard that draws itself.
  • justroll: one command records every screen and the camera, each to its own file.
  • rough-cut-axi: cut video by editing its transcript, review in the browser, render from the shell.
  • short-pipe: an agent finds soundbites in a long talk and exports captioned vertical shorts.
  • m87: an AI triages your GitHub issues and PRs, and you approve before anything ships.
  • baby-menu: a macOS menu bar app that rewrites itself into whatever you ask for.
  • trial-by-combat: two LLMs duel on a 9×9 grid for a relic.
  • fly-with-me: watch a bird fly across an endless generated world. Live at kunchenguid.github.io/fly-with-me.
  • runner-up: GitHub Actions runners on your own machines, with a fresh container or VM for each job.
  • headless: an agent skill that sets up a headless Mac, Linux or Windows machine over SSH without ever seeing the admin password.
  • dotfiles: his Mac setup for agentic engineering, managed with nix-darwin and home-manager.

A note on method

  • The distillations are for orientation only. OPINIONS.md, TOOLS.md and VOICE.md in the kun repo are written by an automated job that summarises his posts every day. We used them to work out which essay or video to read. Nothing on this site quotes them as Kun's own words.
  • Quotes come from primary sources. Every verbatim quote is copied from a README, an essay or a video transcript, and links to the exact source.
  • Star counts are dated. Any star count on this map is as of 2026-11-21.
  • Benchmarks are self-reported. Every benchmark number on this map, including AXI against MCP and plain CLIs, comes from Kun's own runs on his own harnesses. We give the models and run counts he reports. We know of no independent reproduction.
  • Links were checked. Every external link on this page returned HTTP 200 on 2026-11-21. The exception is Medium, which returns 403 to scripts. Each video link was also matched to the @kunchenguid channel through YouTube's oEmbed endpoint.
