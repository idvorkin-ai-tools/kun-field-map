Kun Chen, mapped

Kun Chen was a principal (L8) engineer at Meta, Microsoft and Atlassian. In 2026 he left big tech and started shipping open-source tools for people who build software with coding agents, at a pace of roughly one new repo a week. This site takes the tools one family at a time: what each does, the idea behind it, and how they fit into one view of agent work.

The one-line version. Most tools agents use were built for humans or for protocols, and agents pay for that in tokens, turns and mistakes. Kun designs for the agent first: compact output, live data by default, a clear next step after every command. Then he spends the same care on the human side of the loop: review in the browser instead of screenshots, a gate before anything is pushed, worktrees that are always ready, memory that learns from past sessions. Start with the thesis, or jump to the ten AXI principles.

ARC 2

The human in the loop

Two tools for the point where agent output meets a person: one for reviewing rich work, one for gating what gets pushed.

04
Lavish: HTML is the new markdown
lavish-axi · annotate · poll · playbooks
Agents already produce interactive HTML; Lavish keeps it interactive while you review it. Point at an element, leave a note, and the agent picks it up on its next poll.
05
no-mistakes: a gate in front of git push
no-mistakes · disposable worktree · review, test, docs, lint · clean PR
Push to a local remote instead of origin; an AI pipeline validates the branch in isolation, fixes what is mechanical, parks the judgment calls, and only then forwards it and opens the PR.
ARC 3

Running many agents

Where parallel agents run, and how to leave them working while you are not watching.

06
treehouse: worktrees without managing worktrees
treehouse · pooled worktrees · warm caches · conflict detection
A pool of reusable git worktrees, each leased to one session and returned with its dependencies and build cache intact.
07
gnhf and firstmate: overnight loops and a crew with one liaison
gnhf · firstmate · compact-adviser
gnhf runs a bounded overnight loop of small committed changes. firstmate turns one agent into a first mate that dispatches and supervises a crew. compact-adviser decides when a session is safe to compact.
